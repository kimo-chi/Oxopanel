فایل‌های آپدیت‌شده Oxopanel (PXPanel)
========================================

این دو فایل رو جایگزین/اضافه کن توی روت پروژه (کنار main.py):

1) sales.py  -> فایل جدید. مدیریت پلن‌های فروش، سفارش‌ها و اطلاعات پرداخت (کارت‌به‌کارت + کریپتو).
2) telegram_bot.py -> جایگزین فایل قبلی بشه.

قابلیت‌های اضافه‌شده:
----------------------
1. بخش «💰 فروش و سفارش‌ها» در منوی ادمین ربات تلگرام:
   - ساخت/حذف/فعال‌سازی پلن فروش (نام، مدت به روز، حجم GB، سرعت Mbps، قیمت تومان/USDT)
   - تنظیم شماره کارت بانکی + کیف‌پول کریپتو از طریق ربات
   - مشاهده لیست سفارش‌ها (در انتظار / همه) و تایید یا رد هرکدام

2. فروشگاه برای مشتری‌ها (غیر ادمین) از طریق دستور /buy یا وقتی کاربر غیرادمین /start بزنه:
   - انتخاب پلن از لیست پلن‌های فعال
   - نمایش مبلغ + اطلاعات پرداخت (کارت یا کریپتو) + کد سفارش یکتا
   - ارسال عکس رسید پرداخت از طریق ربات
   - رسید مستقیم برای همه ادمین‌ها با دکمه «تایید» / «رد» ارسال میشه
   - با تایید ادمین: کانفیگ به‌صورت خودکار ساخته و مستقیم برای خریدار در تلگرام ارسال میشه

3. بک‌آپ خودکار به تلگرام (بدون نیاز به داشبورد وب):
   - هر روز ساعت ۴ صبح یک بک‌آپ کامل (کانفیگ‌ها + گروه‌های ساب + دسته‌بندی‌ها + حساب‌های ادمین
     + تنظیمات ربات + پلن‌ها/سفارش‌های فروش) به‌صورت فایل JSON مستقیم توی چت همه‌ی ادمین‌ها ارسال میشه.
   - روز ۲۸ هر ماه، علاوه بر بک‌آپ روزانه، یک نسخه‌ی کامل اضافه هم فرستاده میشه (مناسب چرخه‌ی
     ماهانه‌ی Railway).
   - دکمه‌ی «📦 ارسال بک‌آپ همین الان» زیر «⚙️ تنظیمات پنل ربات» برای گرفتن بک‌آپ فوری.

4. آمار فروش (سفارش در انتظار، فروش موفق، مجموع درآمد) به داشبورد آماری ربات (/stats و دکمه
   «📊 داشبورد و آمار زنده») اضافه شد.

نکات نصب:
----------
- نیازی به پکیج جدید نیست؛ httpx که همین الان توی requirements.txt هست کافیه.
- بعد از جایگزینی فایل‌ها، فقط کافیه سرویس روی Railway ریستارت بشه.
- مدیریت فروش/بک‌آپ فعلاً فقط از طریق ربات تلگرامه (نه داشبورد وب)، چون فایل main.py حجیمه و
  گفتی تمرکز اصلی رو ربات فروش باشه. اگه بعداً خواستی رابط وب هم برای این بخش‌ها اضافه بشه بگو.
